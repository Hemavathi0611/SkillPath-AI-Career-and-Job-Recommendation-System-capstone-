# SkillPath AI — Career and Job Recommendation System

An AI-powered career and job recommendation system built using Python, Machine Learning, Data Analysis, and Streamlit.

## 📌 Project Overview

SkillPath AI helps users explore suitable career paths and job opportunities based on their skills and preferences. It provides career recommendations, job matching, and skill gap analysis to help users identify relevant career opportunities.

## 🚀 Features

- Career Path Recommendation
- Job Recommendation
- Skill Matching and Analysis
- Skill Gap Identification
- Job Filtering by Location and Industry
- Remote Job Preference Filtering
- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Data Visualization
- Interactive Streamlit Web Application

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Jupyter Notebook
- Git & GitHub

## 📊 Data Analysis

The project includes:

- Career Dataset Analysis
- Job Recommendation Dataset Analysis
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Career and Job Recommendation Evaluation
- Data Visualization and Reports

## 🤖 Recommendation System

**Career Recommendation:** Recommends suitable career paths by matching users' skills with the skills required for different careers.

**Job Recommendation:** Identifies relevant job opportunities based on users' skills and selected preferences.

**Skill Gap Analysis:** Highlights matching and missing skills to help users understand which skills they may need to develop.

**Evaluation:** Recommendation scores are calculated using skill coverage percentages.

*Note: Recommendation scores represent skill matches, not hiring probabilities or model accuracy.*

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Hemavathi0611/SkillPath-AI-Career-and-Job-Recommendation-System-capstone-.git
```

### 2. Navigate to the project folder

```bash
cd SkillPath-AI-Career-and-Job-Recommendation-System-capstone-
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
python -m streamlit run app/app.py
```
